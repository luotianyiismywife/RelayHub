## 核心能力

- 统一控制面管理 **CPA / Sub2API / Image2API** 三类账号体系
- 弹性集群编排、大规模并发工作负载执行
- 多通道身份验证消息
- 实时运维遥测
- 多仓库生命周期控制

## 对 RelayHub 的启发

1. **"控制面"概念**：账号/鉴权/遥测从网关里拆成独立控制面 —— 插件化架构里"账号管理"也应该是独立模块而非内联逻辑。
2. **多通道鉴权抽象**：CPA（ChatGPT）、Sub2API、Image2API 各有一套鉴权 —— 插件接口需要把"鉴权方式"做成可插拔的。
3. 该仓库描述偏"运营平台"包装，实际技术含量在号池自动化，可作为 sub2api 生态的配套参考。
